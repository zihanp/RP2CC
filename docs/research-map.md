# 哪些数学想法进了这台编译器

起点是对本地 OpenAI Math 资料库的筛读。六篇实际引用的预印本、章节页码、上游版本和授权见[参考资料](../references/README.md)。稿件编号是研究线索，不是本项目的正确性或速度证明。可复核的数学陈述在本项目的 Lean 源码中，性能数字来自对应的固件和原始回传。

| 线索 | 移植到 RP2350 时做了什么 | 成品证据 |
|---|---|---|
| 268.01：跨道并行的整数取整 | 不直接照搬任意精度整数：把上下两个 16 位二补码值封在一个 32 位字中，推导掩码和符号修正。M33 保留通用版本；Hazard3 另选符号扩展、两次算术右移与 `pack`。 | [全输入证明](../formal/Proofs.lean)、[四条 RV32 运算的等价性](../formal/Hazard3.lean)、[最终机器码核验](../dist/evidence/hazard3-linked.json) |
| 128.01：重叠保存字符串 | 只合并不可变、地址身份不可见的常量对象；对齐和读取边界都是硬约束。不借用无约束超串问题的近似比。 | [六对象样例的最小性证明](../formal/PoolExample.lean)、[最终链接尺寸](../dist/footprint/comparison.json) |
| 130.02：借用并归还暂存坐标 | 单独证明一组纯线性更新能恢复任意初始暂存值。成品只启用了可独立复核的简单抵消规则；没有把坐标引理当作通用寄存器分配器。 | [dirty_restore](../formal/Proofs.lean)、[优化规则与约束](language.md) |
| 187.01、266.02、380.01：让候选与验收分开 | Python 选择候选；独立的 Python 回放器核对生成文件。Lean 直接重新检查源 IR 与候选 IR 的数值语义，不接受“搜索过程看起来正确”代替证明。项目没有引入线性规划求解器。 | [Lean 检查器](../formal/Checker.lean)、[文件入口](../formal/Replay.lean)、[离线验收](../tools/verify_study.py) |
| 本项目的对照：固定仿射递推 | 在模 `2³²` 的环上使用函数复合，编译期从循环计算闭式系数。每步都是精确整数运算，不做统计拟合，也不以近似换速度。 | [可读源程序](../examples/jump.rpm)、[周期实验](experiments.md) |

下一项有区分力的实验，是把同样的数学内核放进一个真实采样链：分别记录端到端吞吐量、每批延迟，以及 CPU 等待 PIO/DMA 的时间。如果瓶颈已经移到外设，即便内核快几十倍，整条链也不会按相同比例加速。
